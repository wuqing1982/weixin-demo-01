# SaaS 第一阶段第八批：Admin Web 场景生成器与批量生成

更新时间：2026-04-05 UTC

目标：

- 为 web admin 增加一个场景生成器，支持浏览器端压缩图片并上传
- 支持一次上传多张图片，批量创建场景生成任务
- 支持在生成时直接指定 `1 个分类 + 多个合集`
- 支持生成完成后自动发布到公开场景库，面向 admin 运营公开内容

范围约束：

- 继续复用现有异步任务队列与 inline worker，不引入新的消息队列中间件
- 批量生成采用“多图上传 -> 每张图创建一条任务”，不做 zip 解包
- 第一期仅支持 Admin web 使用，不改小程序用户侧生成流程
- 分类单选、合集多选；生成参数作用于本次批量任务
- 自动发布仅对 admin web 任务生效，普通用户任务仍只生成私有草稿

- [x] 3. 补 admin 侧批量建任务与任务查询接口
- [x] 4. 补 web admin 多图压缩上传与批量生成页面
- [x] 5. 跑测试、语法检查、服务重载并回填勾选完成
