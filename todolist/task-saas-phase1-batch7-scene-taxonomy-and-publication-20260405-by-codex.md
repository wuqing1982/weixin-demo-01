# SaaS 第一阶段第七批：场景分类、场景合集与 Admin 草稿发布

更新时间：2026-04-05 UTC

目标：

- 为公开场景建立数据库化的场景分类与场景合集管理能力
- 支持 Admin 在发布私有草稿为公开场景时，选择 `1 个分类 + 多个合集`
- 保持当前“拍照生成我的场景”链路不变，不新开第二套 admin 场景生成器

范围约束：

- 本批只做 PostgreSQL 存储，不回退 JSON
- 分类采用单选模型；合集采用多选模型
- 发布入口优先放在 web admin，不先把小程序生成页改成复杂运营页
- 不做前台按分类/合集筛选展示改版；先把管理和发布闭环跑通
- 不做合集封面装修、专题排序页、推荐位等运营扩展

- [x] 3. 补后端 Admin 分类/合集 CRUD 与草稿发布接口
- [x] 4. 补 web admin 的分类管理、合集管理、草稿发布交互
- [x] 5. 跑测试、语法检查、服务重载并回填勾选完成
