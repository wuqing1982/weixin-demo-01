# SaaS 第一阶段第九批：公开场景库筛选与已发布场景覆盖发布

## 目标

- 为小程序公开场景库补上按 `分类` 和 `合集` 的筛选能力
- 为 admin 已发布公开场景补上“从源草稿重新生成并覆盖发布”的操作
- 保持现有 `私有草稿 -> 发布到公开库` 的数据模型不变，继续复用发布 helper

## 范围约束

- 分类仍然是单选
- 合集筛选第一版采用单选筛选入口，避免前台筛选条件过重
- 覆盖发布只对“有源草稿映射”的公开场景开放
- 不做公开库多条件排序和推荐位装修
