# 会员层级体系设计

> 英语场景（e.cps.vin）微信小程序会员体系设计方案

## 设计原则

1. **Freemium 模型**：免费用户可体验基础功能，付费解锁完整体验
2. **渐进解锁**：层级越高，功能覆盖越完整，形成升级动力
3. **虚拟商品 + 时效权益**：会员为时效性权益，点数为消耗型虚拟商品
4. **低门槛高留存**：免费层足够体验产品价值，付费层提供真正有用的增强

---

## 会员层级总览

| 层级 | 代号 | 类型 | 价格 | 核心定位 |
|------|------|------|------|----------|
| **免费用户** | `free` | 默认 | ¥0 | 体验产品，了解场景学习模式 |
| **基础会员** | `basic` | 月付/年付 | ¥19.90/月 或 ¥128/年 | 解锁完整学习体验 |
| **高级会员** | `pro` | 月付/年付 | ¥39.90/月 或 ¥258/年 | 高频学习用户 + 创作者 |
| **点数包** | `credit_pack` | 一次性购买 | ¥4.90 ~ ¥29.90 | 非会员场景生成补充 |

## 各层级详细定义

### 免费用户（free）

**目标**：让用户快速体验产品核心价值，建立使用习惯。

| 维度 | 权限 |
|------|------|
| 场景浏览 | 可浏览所有公开场景列表 |
| 场景学习 | 每日可学习 **3 个**公开场景（含 TTS 播放） |
| 场景生成 | 注册赠送 **1 次**生成点数（一次性） |
| TTS 语音 | 基础音色 |
| 热点交互 | 可点击查看，不可编辑 |
| 个人场景 | 可查看自己生成的场景 |
| 学习记录 | 不保留学习历史 |

### 基础会员（basic）

**目标**：解锁完整学习体验，形成每日使用习惯。

| 维度 | 权限 |
|------|------|
| 场景浏览 | 可浏览所有公开场景列表 |
| 场景学习 | **无限**公开场景学习 + TTS 播放 |
| 场景生成 | 每月赠送 **5 次**生成点数（月末清零） |
| TTS 语音 | 基础音色 + 2 种高级音色 |
| 热点交互 | 可编辑自己场景的热点 |
| 个人场景 | 无限查看自己生成的场景 |
| 学习记录 | 保留最近 **30 天**学习历史 |
| 场景收藏 | 最多 **10 个**收藏 |

### 高级会员（pro）

**目标**：高频学习 + 场景创作，覆盖重度用户全部需求。

| 维度 | 权限 |
|------|------|
| 场景浏览 | 可浏览所有公开场景列表 |
| 场景学习 | **无限**公开场景学习 + TTS 播放 |
| 场景生成 | 每月赠送 **20 次**生成点数（月末清零） |
| TTS 语音 | 全部音色（基础 + 高级 + 精品音色） |
| 热点交互 | 可编辑所有场景热点（权限范围内） |
| 个人场景 | 无限查看自己生成的场景 |
| 学习记录 | **永久**学习历史 |
| 场景收藏 | **无限**收藏 |
| 专属功能 | 优先生成队列、单词本导出、学习统计报告 |

### 点数包（credit_pack）

一次性购买的消耗型虚拟商品，不绑定会员状态。

| 规格 | 点数 | 原价 | 售价 | 单价 |
|------|------|------|------|------|
| 体验包 | 5 次 | ¥9.90 | ¥4.90 | ¥0.98/次 |
| 标准包 | 20 次 | ¥29.90 | ¥9.90 | ¥0.50/次 |
| 超值包 | 50 次 | ¥49.90 | ¥19.90 | ¥0.40/次 |
| 大师包 | 100 次 | ¥99.90 | ¥29.90 | ¥0.30/次 |

> 点数永不过期，会员和非会员均可购买。

## 定价策略

### 价格锚定

```
高级月卡 ¥39.90  ←  锚点
高级年卡 ¥258    =  ¥21.50/月（省 46%）  ←  推荐选择
基础月卡 ¥19.90  ←  入门选择
基础年卡 ¥128    =  ¥10.67/月（省 46%）  ←  性价比之选
```

### 年付折扣

所有年付方案统一为月付价格的 **~54%**（约省 46%），与行业惯例一致：
- 基础：19.90 × 12 = 238.80 → **¥128**（省 ¥110.80）
- 高级：39.90 × 12 = 478.80 → **¥258**（省 ¥220.80）

### 促销策略（预留）

| 策略 | 说明 | 实现方式 |
|------|------|----------|
| 新用户首月特惠 | 首月半价 | SKU 配置 `firstMonthPrice` |
| 限时折扣 | 节日活动 | SKU `salePrice` 调整 |
| 搭赠 | 买年卡送点数 | 多 benefit 绑定 |
| 邀请码 | 老用户邀请新用户各得点数 | 独立邀请系统 |

## 升降级规则

### 升级

- 升级即时生效
- 原有剩余天数按比例折算为更高层级的天数（按价格比例）
- 例：基础会员剩余 15 天（价值 ¥9.95），升级高级 → 折算为 9.95/39.90×30 ≈ 7 天高级会员

### 降级

- 降级在当前周期结束后生效
- 已享有的高级功能立即保留至到期日
- 超出降级层级限制的数据（如收藏超 10 个）标记为"只读"，不删除

### 取消

- 取消后到期日之前仍可使用
- 到期后回退为免费用户
- 学习记录保留 90 天，之后清理
- 点数余额永久保留

## 实体关系映射

### 对应现有数据库表

```
products (产品)
├── product_membership_basic   → 基础会员
│   ├── sku_basic_monthly      → 月卡 ¥19.90
│   └── sku_basic_annual       → 年卡 ¥128
├── product_membership_pro     → 高级会员
│   ├── sku_pro_monthly        → 月卡 ¥39.90
│   └── sku_pro_annual         → 年卡 ¥258
└── product_credit_scene       → 场景点数包
    ├── sku_credit_5           → 5次 ¥4.90
    ├── sku_credit_20          → 20次 ¥9.90
    ├── sku_credit_50          → 50次 ¥19.90
    └── sku_credit_100         → 100次 ¥29.90

sku_benefits (权益)
├── membership 类  → entitlement_type = 'membership', entitlement_code = 'basic'|'pro'
└── credits 类     → credit_type = 'scene_generation_credits'

user_entitlements (用户权益)
├── membership  → 记录层级、开始/到期时间
└── credits     → 通过 user_credit_accounts 管理余额
```

## 阶段实施建议

### Phase 1：MVP（当前阶段）

- 保留现有基础会员月卡 + 点数包 20 次
- **后端**：实现场景访问次数限制（免费用户 3 次/天）
- **后端**：实现点数消耗（场景生成时扣减余额）
- **前端**：产品页显示会员状态和点数余额

### Phase 2：完善层级

- 上线高级会员（pro）
- 年付选项
- 完整的升降级逻辑
- 学习记录功能
- 场景收藏功能

### Phase 3：增长

- 邀请码/推荐系统
- 首月特惠
- 学习统计报告
- 单词本导出
