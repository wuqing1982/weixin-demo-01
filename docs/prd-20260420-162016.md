# 英语场景 (English Scene) 产品需求文档

**版本**: 1.0
**创建日期**: 2026-04-20
**线上域名**: `https://e.cps.vin`

---

## 1. 产品概述

### 1.1 产品定位

微信小程序 + 后端服务，为儿童提供**沉浸式英语学习体验**。通过全景图/VR 场景与热点交互的方式，让用户在虚拟场景中学习英语词汇和句子，配合 TTS 语音播放。

### 1.2 目标用户

- **主要用户**: 6-12 岁儿童
- **付费决策者**: 家长

### 1.3 核心价值主张

- 场景化学习：将英语学习融入真实生活场景
- 互动兴趣：通过探索热点激发学习主动性
- 效果可视：家长可查看学习进度和成果

## 2. 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 游客 | 未登录用户 | 仅可浏览公开场景 |
| 普通用户 | 微信登录用户 | 访问授权场景、创建场景、学习记录 |
| 热点编辑者 | 被授权编辑场景热点的用户 | 添加/编辑/删除场景热点 |
| 管理员 | 后台管理账号 | 全部系统管理权限 |

## 3. 功能模块

### 3.1 认证模块

#### 3.1.1 微信登录

- 小程序通过 `wx.login` 获取 code
- 后端调用微信 `code2Session` 获取 openid
- 返回 JWT access_token + refresh_token
- 支持 token 刷新和登出

#### 3.1.2 会员体系

- 会员等级：免费版、付费版
- Credits 虚拟货币（用于兑换付费内容）
- 权益摘要展示

### 3.2 场景模块

#### 3.2.1 公共场景

- 预置场景库（早餐、动物园等）
- 分类浏览（category）
- 专题集合（collection）
- 免费/付费标记

#### 3.2.2 用户场景

- 用户上传图片生成场景
- 场景元数据：标题、描述、分类、封面
- 私有/公开属性

#### 3.2.3 热点系统

- 热点位置：x, y 坐标（相对比例 0-1）
- 热点内容：英语词汇/句子、TTS 音频资源
- 热点操作：点击播放音频、显示翻译
- 编辑权限控制

#### 3.2.4 AI 场景生成

- 用户上传图片
- 后端调用 AI 视觉模型分析图片内容
- 自动生成热点建议
- 调用 TTS 生成朗读音频
- 异步任务模式

### 3.3 电商模块

#### 3.3.1 商品目录

- Product（商品）→ SKU（具体商品项）
- SKU 包含权益配置（credits、会员时长等）
- 上架/下架状态

#### 3.3.2 订单流程

- 创建订单
- 微信支付（JSAPI）
- 支付回调处理
- 订单状态同步

#### 3.3.3 CDK 兑换

- 管理员生成 CDK 码
- 用户兑换 CDK 获取权益
- 兑换记录查询

### 3.4 Admin 后台

#### 3.4.1 用户管理

- 用户列表查看
- 用户详情
- 封禁/解封
- 权限授予/撤销

#### 3.4.2 商品管理

- 商品创建/编辑
- SKU 管理
- 上架/下架

#### 3.4.3 场景管理

- 公共场景创建/编辑
- 场景分类/专题管理
- 批量操作（可见性、免费、分类）
- AI 生成任务管理

#### 3.4.4 订单管理

- 订单列表
- 订单详情

#### 3.4.5 CDK 管理

- CDK 生成
- CDK 批量删除
- 兑换记录

### 3.5 视频导出模块

- 场景导出为视频
- 异步生成任务
- 进度查询
- 文件保全（过期清理）

## 6. 用户流程

### 6.1 首次使用流程

```
1. 用户打开小程序
2. 调用 wx.login 获取 code
3. POST /api/auth/wechat/login
4. 获取 access_token，缓存到本地
5. 跳转首页，展示公共场景列表
```

### 6.2 学习流程

```
1. 用户浏览场景库
2. 选择场景进入
3. 全景图加载
4. 点击热点
5. 播放 TTS 音频
6. 显示英语内容和翻译
7. 学习记录留存
```

### 6.3 购买流程

```
1. 用户进入商品页
2. 选择 SKU
3. POST /api/orders 创建订单
4. POST /api/orders/{order_id}/pay 发起支付
5. 小程序调起 wx.requestPayment
6. 支付成功后 POST /api/orders/{order_id}/payment-sync
7. 后端更新订单、发放权益
```

### 6.4 AI 场景生成流程

```
1. 用户上传图片
2. POST /api/uploads/image
3. POST /api/my/tasks/scene-generate
4. 后端创建异步任务
5. InlineSceneWorker 处理：
   a. 调用视觉模型分析图片
   b. 生成热点建议
   c. 调用 TTS 生成音频
   d. 保存生成的场景
6. 用户轮询任务状态
7. 完成后查看新场景
```

## 8. 非功能性需求

### 8.1 性能

- API 响应时间 < 500ms（正常网络下）
- 场景图片加载 < 3s（正常网络下）
- TTS 音频生成 < 5s

### 8.2 可用性

- 7x24 小时服务
- 支付回调需幂等处理
- 关键接口需重试机制

### 8.3 安全

- JWT token 需设置过期时间
- 敏感操作需鉴权
- 支付回调需验签
- 用户输入需校验

### 8.4 扩展性

- 存储后端可切换（JSON → PostgreSQL）
- 支付模式可切换（mock → real）
- 热点编辑器可禁用
